# Hitsounds Pack
A large collection of hitsound files for games.

## About
* 200+ different hitsounds
* All files are in .wav format and properly encoded

## Sources
**Most of the hitsounds in this collection were gathered:**
* [The Biggest Hitsound Pack](https://hackvshack.net/threads/the-biggest-hitsound-pack-50-wav-files.3904/)
* [Hitsounds by qwwawa](https://yougame.biz/threads/357471/)
* [Neverlose.cc Hitsounds](https://github.com/Kittywy/Neverlose.cc-hitsounds)

## How to use
1. Download [archive](https://github.com/ar4yc/Hitsounds/archive/refs/heads/main.zip) and unzip it
2. Place hitsounds in your sound folder (for csgo with custom hitsound lua place files in `csgo/sound/hitsounds`)
3. Select needed hitsound
